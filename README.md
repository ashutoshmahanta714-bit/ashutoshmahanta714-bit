## Featured Project

### [DocIntel — Document Intelligence RAG System](https://github.com/ashutoshmahanta714-bit/document-intelligence-rag)

A full-stack Retrieval-Augmented Generation application for uploading documents and asking grounded questions about their content.

- Parses PDF, DOCX, TXT, CSV, and Markdown files.
- Generates sentence-transformer embeddings and stores them in ChromaDB.
- Retrieves relevant passages using cosine similarity.
- Produces source-aware answers using an LLM.
- Includes a FastAPI backend and React/Vite frontend.

**Tech:** Python • FastAPI • ChromaDB • Sentence Transformers • OpenAI API • React
